Excel Fundamental Booster -- Solutions
Project Overview
Excel Fundamental Booster -- Solutions is an Excel workbook designed
to practise and demonstrate essential Excel formulas and data-analysis
functions. It contains sample student, sales, and employee datasets,
along with a solutions sheet that presents formula-based calculations
and lookup results.
Workbook Contents
The workbook contains four worksheets:

Excel Functions Demonstrated
The workbook demonstrates the following functions and techniques:
- Logical functions: IF, nested IF, AND, and OR for grade
  classification and eligibility checks.
- Conditional calculations: COUNTIFS, SUMIFS, and AVERAGEIFS
  for counting, summing, and averaging records that meet criteria.
- Lookup and reference functions: VLOOKUP, INDEX, MATCH,
  XLOOKUP, and XMATCH for retrieving values and locating records.
- Dynamic reference functions: INDIRECT and OFFSET for
  referencing ranges dynamically.
- Filtering: FILTER for extracting student records that meet a
  marks threshold.
- Date functions: YEAR, TEXT, DATEDIF, and date subtraction
  for joining year, month, tenure, and days employed.
- Text functions: LEFT, FIND, UPPER, and LOWER for
  extracting and changing text.
- Math and rounding functions: ROUND, CEILING, and FLOOR for
  rounding salary and numeric values.
Main Tasks Covered
1. Calculate student averages and assign grades using nested IF
   formulas.
2. Identify students scoring above specified thresholds and apply
   logical conditions to subject marks.
3. Calculate conditional counts, totals, and averages using COUNTIFS,
   SUMIFS, and AVERAGEIFS.
4. Retrieve product prices, student names, sales amounts, and employee
   salaries using lookup functions.
5. Use INDIRECT and OFFSET to calculate sales totals from
   referenced ranges.
6. Analyse employee joining dates and calculate tenure and days
   employed.
7. Apply text and rounding functions to employee and numeric data.
8. Filter students whose Math marks are above a selected threshold.
How to Use
1. Open project1.xlsx in Microsoft Excel.
2. Review Sheet2, Sheet3, and Sheet4 to understand the student,
   sales, and employee datasets.
3. Open Sheet5 to review the task descriptions and example solution
   outputs.
4. Change the input values in the solution area where applicable to
   test different lookup and calculation results.
5. If a formula result does not update, check that Excel calculation is
   set to Automatic and recalculate the workbook.
Requirements
- Microsoft Excel with support for the functions used in the workbook.
- Excel 365 or a recent Excel version is recommended for dynamic-array
  functions such as FILTER and modern lookup functions such as
  XLOOKUP and XMATCH.
Some newer functions may not be available in older spreadsheet
applications or older Excel versions.
Notes
- The workbook uses sample student, sales, and employee records for
  practice.
- Formula results that depend on TODAY() can change as the current
  date changes.
- The solution sheet contains example outputs; edit the input cells to
  explore the formulas and test other cases.
